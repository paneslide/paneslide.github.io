Install PaneSlide, play offline, and keep your progress safe

How to add PaneSlide to your home screen on Android, iPhone, iPad and desktop, how offline play works, where your progress is stored, and how to use a progress code to move to a new device.

PaneSlide runs in your web browser, with nothing to download from an app store. You can still install it so it opens like an app, and it keeps working without an internet connection. This guide explains how, and how to keep your progress safe.

Installing on Android (Chrome and similar browsers)

  1. Open paneslide.github.io in Chrome.
  2. Open Settings in the game (the gear button). If your browser supports installing, you will see an 📲 Install app button. Tap it and confirm.
  3. If you do not see the button, open Chrome's menu (⋮) and choose Add to Home screen or Install app.

PaneSlide then appears on your home screen with its own icon and opens in its own window without the browser's address bar.

Installing on iPhone and iPad (Safari)

Safari does not show an install button inside web pages, so the steps are a little different:

  1. Open paneslide.github.io in Safari.
  2. Tap the Share button (the square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen, then Add.

The PaneSlide icon will appear on your home screen.

Installing on a laptop or desktop

In Chrome or Edge on Windows, macOS, Linux or ChromeOS:

  1. Open paneslide.github.io.
  2. Use the 📲 Install app button in Settings or at the bottom of the page if it appears, or the small install icon at the right of the address bar.

The installed app opens in its own window. On a big screen, PaneSlide uses a wider layout with a larger board and a Controls panel. See keyboard and mouse controls.

Some browsers, such as Firefox on desktop, do not offer installing websites as apps. PaneSlide works just as well in a normal browser tab there.

Playing offline

After your first visit, PaneSlide saves the game and the pages it needs on your device. From then on:

  • Levels and daily puzzles work offline. Every level and daily is built on your device, so no connection is needed to play.
  • Guides you have already opened, and the main guides, are usually available offline too.
  • When you are back online, the game checks for a new version in the background. If there is one, a message says a new version is ready, with a Refresh button. Your progress is not affected by updating.

If you clear your browser's site data for PaneSlide, the offline copy is removed and will download again on your next visit.

Where your progress is stored

PaneSlide has no accounts and no server for game data. Your progress, stars, shards, settings and daily streak are saved only in your browser on this device, using the browser's local storage.

That has some useful consequences:

  • It is private. Your progress never leaves your device unless you copy a progress code yourself.
  • It is per browser. Chrome and Safari on the same phone keep separate progress. So do an installed app and a browser tab in some cases.
  • Clearing site data deletes it. If you clear "cookies and site data" for PaneSlide, or for all sites, your progress is removed. Private or incognito windows also forget everything when you close them.

Moving to a new phone or computer: the progress code

To carry your progress to another device or browser:

  1. On the old device, open Settings and tap 💾 Progress code.
  2. Tap 📋 Copy code and keep the code somewhere safe, for example in a note or a message to yourself.
  3. On the new device, open PaneSlide, go to Settings → 💾 Progress code, paste the code into Load a code and confirm.

Loading a code replaces the progress on the new device with the progress from the code, so do it before you start playing there. The game asks you to confirm first.

Tip. Copying a progress code now and then is a simple backup. If you ever change phones or clear your browser, you can pick up exactly where you left off.

Troubleshooting

  • No install button? Your browser may not support it, or PaneSlide may already be installed. Use the browser menu or Safari's Share steps above.
  • The game looks out of date? Close all PaneSlide tabs and windows and open it again, or tap Refresh when the "new version" message appears.
  • Progress missing after installing on iPhone? On iOS, a home screen app can keep its storage separate from Safari. Use a progress code to move your progress across.
